# Production fork contracts (initial milestone)

Package: `@wulianpu/qwen-audio-agent`, GitHub Packages. Version `2.0.1-showroom.1` is a candidate, not production-qualified. Upstream baseline: `7e249fc`.

Run `npm ci --ignore-scripts`, targeted contract tests, `npm run build`, `npm run fork:check`, and `npm pack --ignore-scripts`. The fork workflow uploads the tarball and integrity manifest; publishing requires an explicit manual `publish` input. The inherited upstream Release workflow is disabled on this fork. Configure repository package access before consuming from another repository. GitHub package visibility and access must be checked before the first publication. No package has been published by this implementation.

Client Event definitions may supply an async `receipt(event)` returning a JSON object. It runs after `handle` and `project`. The router returns `receipt`; GCP returns it as `client.event.publish.result.result`. Concurrent retries share one operation, and completed duplicates replay a detached receipt within the existing bounded deduplication window. Only server-registered definitions generate receipts. A receipt callback failure propagates; handlers must still make external side effects idempotent across failures, restarts and TTL expiry.

`ConversationSync.retireSession(ownerId, sessionId)` removes the in-memory conversation. `SessionJournalRegistry.retireSession(ownerId, sessionId)` serializes durable retirement, purges conversational events, and retains latest unresolved task snapshots (including pending delivery). Later non-task journal events are discarded; terminal delivered tasks are removed. The registry is exported as `./session-journal-registry`. Transport `retireSession(ownerId, sessionId)` clears the matching replay buffer. These are host-side APIs, not remotely callable deletion commands. Hosts must fence/disconnect old sessions and stop their producers before retirement; deletion of a replay buffer is not an admission revocation. Never reuse retired visitor IDs. Retained task snapshots may contain business data and remain subject to host retention policy.

This milestone does not replace the agent dependency or remove its compatibility patches: the other seven compatibility capabilities remain required. Unity/Xingyun output and the NativeAudioAdapter C++ runtime prohibition remain unchanged. Tests never start the native runtime.
